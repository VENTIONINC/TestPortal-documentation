# User Guides

Sign in to your Test Portal instance and select a project before exploring its test data.

## Executions and results

An execution groups a test run. Results describe individual tests within that run, including their status and available failure details. Start from the results view to inspect the data received from uploaded reports.

## Issues

Issues represent problems investigated across test failures. Linked failure information helps you relate a result to an existing issue.

## Test Management System

Create structured Test Scenarios, organize them with folders and suites, connect them to automated evidence, and run them manually. Manual run history preserves the saved snapshot even when a scenario is later edited.

## Before investigating missing results

Confirm that the upload targeted the same instance and project you are viewing. Check the upload response as well as the test command output. See the [API overview](../api/index.md) for the upload interfaces.
