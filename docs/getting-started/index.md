# Getting Started

Before submitting your first report, identify the Test Portal instance your team uses and the project that should receive your test results.

## Prepare access

1. Obtain your instance URL and sign-in instructions from its administrator.
2. Sign in and select the project you want to work with.
3. Obtain an upload API key for that project if you plan to submit reports through the CLI.
4. Choose a supported source report format for your test framework.

Login behavior depends on the instance configuration. A web login token, an upload API key, and an MCP token serve different purposes; use the credential required by the interface you are connecting to.

## Choose an integration

Read the [integration overview](../integrations/index.md) to identify the report format, then review the [CLI overview](../cli/index.md) or [API overview](../api/index.md).
