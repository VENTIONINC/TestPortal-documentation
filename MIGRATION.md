- Assets: existing client logo/image assets were located but not copied. No sanitized product screenshots were established. Add screenshots only after data, credentials, suitability and asset rights are reviewed.

## Discrepancies and decisions

| Topic | Evidence and decision |
| --- | --- |
| Package and registry | CLI package is `@vention-test-portal/test-portal-integration-cli` v1.1.2, published registry configured as GitHub Packages. README badges point to npm and old organization URLs; actual released-package availability/access remains unverified. Do not promise anonymous npm installation. |
| Executable | `package.json` installs `test-portal-cli`; Commander displays `test-convert`. Document installed bin, retain display-name discrepancy in audit. |
| Required arguments | README includes positional `report.json` examples. `src/cli.ts` requires `-i/--input` and `-t/--type`. Use explicit flags. |
| Versions | CLI engines specify Node >=18; backend manifest >=22.15 while README says 18+. Docs site's Node requirement is independent. Do not use one ecosystem-wide minimum. |
| Providers | Registry includes Playwright, Jest, Cypress, JUnit, Vitest, NUnit, Mocha, Pytest and TestNG; README option lists omit TestNG. Initial detailed guides remain Playwright/Jest/Cypress. |
| Format boundaries | Playwright validator expects suites/config; Jest expects testResults and numeric counts; Cypress expects results/stats.tests. Cypress conversion iterates only top-level results and assumes array titles. The guide supplies an explicitly tested flatten/title-normalization recipe and rejects count/state mismatches; unrestricted direct Mochawesome compatibility is not claimed. Jest JSON also needs name-to-testFilePath normalization, reproduced with Jest 29.7.0. |
| Output | Files/stdout/webhooks contain CTRF, despite a README “Unified Output Format” example showing the internal intermediate shape. Default local filename ends in `.unified.json`. A configured webhook suppresses implicit file output; explicit output still permits upload. `--stdout` does not disable submission. |
| Retry semantics | Default timeout 30000 ms, attempts 3, initial delay 1000 ms; loop counts total attempts, not three retries after the initial attempt. Exponential delay capped at 10000 ms. |
| Exit behavior | Converter logs webhook rejection and returns normally. CLI exit 0 is not upload acceptance. Conversion/output failures throw and CLI exits 1. The implemented first-report and CI guides use separate cURL submission with HTTP/body/count assertions; a local HTTP 401 mock reproduces CLI exit 0. |
| TLS option | `--no-verify-ssl` passes a plain object as Axios httpsAgent. Successful TLS bypass is not verified; do not recommend it as a working remedy. |
| Environment | TEST_PORTAL_URL default webhook; TEST_PORTAL_API_KEY becomes X-API-Key. EXECUTION_TYPE/TEST_ENVIRONMENT enrich CTRF; CI default environment is ci. CI/git metadata env values are also consumed; distinguish these from required integration credentials. |
| Upload contracts | `/api` runtime mount plus `/v2/upload-ctrf-report[-api-key]` or `/v2/upload-json-report[-api-key]`. JSON file in multipart `report`, 50 MiB limit. JWT path takes projectId; API key supplies its project. CLI sends CTRF, not raw Playwright JSON. CTRF success is 201; controller parse/input failures return 400. Do not infer a complete error taxonomy from schemas alone. |
| Credential types | Upload X-API-Key, web/API Bearer JWT and MCP Bearer token have distinct purposes. Auth configuration includes local/cognito and approval-dependent states. Do not assume self-signup always grants immediate access. |
| MCP connection | `/api/v2/mcp` uses authenticated Streamable HTTP POST/GET/DELETE and session IDs. INSPECT_MCP_SERVER sample omits required Bearer header. Its inspector script uses build/index.js while build/server use dist/index.js; do not copy this setup command. |
| MCP inventory | Registered status/time, issue read/create, result read/stats, assumption operations, execution lookup, error assign/review/bulk review, spec lookup. Docs list get-mock-issues, which is not registered; docs omit get-results-stats. getIssuesWithStats is exported but unregistered. Exclude mock/unregistered tools.
